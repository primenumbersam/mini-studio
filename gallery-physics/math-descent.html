1) 선형 이진 분류와 분리 초평면 (Hyperplane)

입력 벡터 $x = (x_1, x_2)^T$와 클래스 라벨 $y \in \{-1, +1\}$에 대해 선형 분류기는 결정 함수 $f(x) = w^T x + b = w_1 x_1 + w_2 x_2 + b$를 정의한다. $$f(x) = 0 \iff w_1 x_1 + w_2 x_2 + b = 0$$ 이 직선이 클래스를 양분하는 결정 초평면(Decision Hyperplane)이다.

2) 마진(Margin)과 기하학적 정의

초평면을 기준으로 양의 클래스와 음의 클래스가 위치하는 안전 경계면을 각각 다음과 같이 설정한다. $$w^T x + b = +1 \quad \text{및} \quad w^T x + b = -1$$ 두 평행한 마진 경계선 사이의 기하학적 거리(마진 폭, Margin Width)는 초평면의 법선 벡터 $w$의 크기에 반비례한다. $$\text{Margin Width} = \frac{2}{\|w\|} = \frac{2}{\sqrt{w_1^2 + w_2^2}}$$ 따라서 마진 폭을 극대화($\max \frac{2}{\|w\|}$)하는 것은 가중치 벡터의 크기를 최소화($\min \frac{1}{2}\|w\|^2$)하는 문제와 동치이다.

3) 소프트 마진(Soft-Margin)과 힌지 손실(Hinge Loss)

실제 데이터는 완벽히 선형 분리되지 않거나 노이즈가 존재하므로, 마진 침범 및 오분류를 허용하는 슬랙 변수(Slack Variable) $\xi_i$를 도입한다. 이는 힌지 손실(Hinge Loss) 함수로 표현된다. $$\ell_{\text{hinge}}(y, f(x)) = \max\left(0,\, 1 - y(w^T x + b)\right)$$ 소프트 마진 SVM의 원문제(Primal Objective)는 마진 극대화 규제항과 힌지 손실의 합으로 정의된다. $$J(w, b) = \frac{1}{2}\|w\|^2 + \frac{C}{m} \sum_{i=1}^{m} \max\left(0,\, 1 - y^{(i)}(w^T x^{(i)} + b)\right)$$ 여기서 $C$는 마진 폭과 오분류 페널티 사이의 균형을 조절하는 하이퍼파라미터다. $C$가 클수록 마진 위반을 엄격하게 제한하고, $C$가 작을수록 마진 폭을 넓히는 데 집중한다.

4) 서포트 벡터(Support Vector)의 조건

마진 점수 $s_i = y^{(i)}(w^T x^{(i)} + b)$에 따라 데이터 포인트는 세 가지 영역으로 나뉜다.

  • $s_i > 1$: 마진 스트리트 외부에 올바르게 분류된 데이터. 힌지 손실은 $0$이며, 가중치 그래디언트에 기여하지 않는다.
  • $s_i = 1$: 정확히 마진 경계선 위에 걸쳐 있는 핵심 서포트 벡터(Support Vector).
  • $s_i < 1$: 마진 스트리트 내부를 침범했거나 반대편으로 오분류된 포인트. $1 - s_i$만큼의 손실이 발생하며 서포트 벡터로 취급되어 초평면을 밀어내는 그래디언트를 생성한다.

5) 서브그래디언트 경사하강법 (Subgradient Descent)

힌지 손실은 $s_i = 1$에서 꺾이는 비미분 점이 존재하므로 일반 미분 대신 서브그래디언트(Subgradient)를 사용하여 경사하강법을 적용한다. $$\nabla_w J = w + \frac{C}{m} \sum_{i:\, y^{(i)} f(x^{(i)}) < 1} \left( -y^{(i)} x^{(i)} \right)$$ $$\nabla_b J=\frac{C}{m} \sum_{i:\, y^{(i)} f(x^{(i)}) < 1} \left( -y^{(i)} \right)$$ 매 반복마다 학습률 $\alpha$를 곱하여 파라미터를 갱신한다: $$w \leftarrow w - \alpha \nabla_w J, \quad b \leftarrow b - \alpha \nabla_b J$$ 이 과정을 통해 모든 점이 아닌 마진을 침범한 서포트 벡터들만의 외력에 의해 초평면이 최적의 균형 위치를 찾아 수렴한다.
