03. 주요 포맷 비교 분석

JPEG

범용 표준

모든 환경에서 호환되지만 압축 효율이 낮고 투명도(Alpha)를 지원하지 않습니다.

AVIF

차세대 추천

JPEG 대비 절반 수준의 용량으로 고화질을 유지하며, HDR과 투명 배경을 모두 지원합니다.

동일 화질 기준 상대 파일 크기 (%, 낮을수록 우수)

PNG

웹 무손실 표준

투명 배경과 무손실 보존이 필요한 UI·스크린샷에 적합하지만 사진에서는 용량이 큽니다.

QOI

초고속 처리

단순한 알고리즘으로 PNG와 비슷한 압축률을 유지하면서 인코딩·디코딩 속도가 매우 빠릅니다.

상대 처리 시간 비교 (낮을수록 빠름)

SVG

웹 네이티브

XML 기반 벡터 포맷으로 해상도 손실 없이 확대되며 CSS/JS로 직접 제어할 수 있습니다.

AI / PDF

편집·인쇄용

레이어, 아트보드, CMYK 색상 정보를 보존하여 인쇄물 및 디자인 원본 보관에 사용합니다.
