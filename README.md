## 일반 구매자를 위한 떠먹여 주기식 배포 

검로드(Gumroad)와 크몽(Kmong)의 비개발자 구매자에게 '도메인 구매 비용 외 평생 유지비 0원'이라는 소구점을 유지하면서 인지부하를 없애려면, 플랫폼은 Cloudflare로 단일화하되 패키징 구조와 안내 방식을 구매자 친화적으로 재설계하는 전략

글로벌 셀프서비스 구매자가 주류인 Gumroad에서는 Cloudflare 직행 링크와 3단계 스크린샷이 담긴 1페이지짜리 PDF(또는 단일 HTML 가이드)를 상품에 포함해 배포. 반면 대행을 선호하는 국내 Kmong 시장에서는 기본 상품 가격에 더해 3만 원에서 5만 원 상당의 '도메인 연결 및 평생 무료 서버 세팅 대행' 옵션을 추가 옵션(Upsell)으로 걸어둔다.
